# TechCenter

## 1. Punto de partida

Recuperando los wireframes del listado de talleres, detalle de un taller, formulario de inscripción y confirmación.
Convertiremos la plataforma de talleres diseñada en la UD1 en un prototipo web coherente. Primero
en grupo se crea una guía visual (Guia de estilos techcenter.pdf); después cada integrante implementará una pantalla o una parte delimitada y,
finalmente integraremos el trabajo. Se evaluará tanto el resultado común como la aportación individual. El prototipo
podrá servir de base para continuar el proyecto en Despliegue.


## 2. Aportación individual e integración

Cada integrante se responsabilizará de una pantalla o parte concreta acordada con el grupo. Si el número de
integrantes no coincide con las cuatro pantallas, repartid también componentes comunes, adaptación a móvil,
pruebas e integración de forma equilibrada. Cada persona debe escribir código propio y poder explicar sus
decisiones. Usad HTML semántico, hojas CSS externas y la misma guía de estilo. La plataforma integrada debe
enlazar el listado, el detalle, el formulario y la confirmación de manera demostrable; las acciones simuladas
deben quedar identificadas en la memoria.

## 4. Cómo abrir el proyecto

1. Descargar o clonar el repositorio del proyecto.	 `git clone https://github.com/AlexisVennegas/TechCenter.git `
2. Abrir la carpeta del proyecto en Visual Studio Code o en otro editor de código.
3. Abrir el archivo HTML de la página principal en un navegador (index.html), o utilizar la extensión Live Server de Visual Studio Code.
4. Navegar por las páginas mediante los enlaces disponibles para comprobar el funcionamiento del prototipo integrado.


## 5. Funciones simuladas

El proyecto es un prototipo web, por lo que algunas funcionalidades son demostrativas y no están conectadas a un servidor ni a una base de datos.

* **Listado de talleres:** permite visualizar los talleres disponibles.
* **Detalle del taller:** muestra información específica de cada taller.
* **Formulario de inscripción:** permite introducir los datos necesarios para realizar una inscripción de prueba.
* **Confirmación:** muestra la página de confirmación después del proceso de inscripción simulado.

Las inscripciones no se almacenan de forma permanente ni se envían a un sistema real.
